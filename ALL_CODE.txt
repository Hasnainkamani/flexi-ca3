# PaisaWise — Smart Expense Tracker

A full-stack personal finance app to track income, monitor expenses, set budgets, chase savings goals, and visualize where every rupee goes — all in a beautiful, secure dashboard.

## Features

- **Dashboard** — Gradient balance card with sparkline, income/expense stat cards with 6-month trends, interactive donut chart, smooth cash-flow line chart, daily spending bars, and smart insights (savings health, top category, month-over-month comparison)
- **Transactions** — Add, edit, delete, search, filter, and sort income/expense entries. Export to CSV.
- **Analytics** — Full-year view with income vs. expense bar chart, category breakdown donut, ranked top-categories list, month-over-month trend cards, savings rate, average transaction size, and best savings month highlight
- **Budgets** — Set monthly per-category spending limits with progress bars, over-budget alerts, and an overall month summary
- **Savings Goals** — Create financial goals with targets, target dates, and progress tracking. Quick-add funds with preset amounts.
- **Categories** — Custom income/expense categories with color picker. 11 default categories auto-seeded for new users.
- **Dark Mode** — Toggle between light and dark themes; saved to localStorage
- **Landing Page** — Marketing page with hero, feature grid, animated showcase, and call-to-action
- **Authentication** — Email/password sign-up and sign-in via Supabase Auth
- **Security** — Row Level Security (RLS) on every table; each user only sees their own data

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Supabase (PostgreSQL, Auth, Row Level Security)
- **Charts:** Custom SVG components (Donut, Line, Bar, Sparkline) — no chart library

## Getting Started

### Prerequisites

- Node.js 18+
- A Supabase project (free at [supabase.com](https://supabase.com))

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root:

```env
VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### Database Setup

Run the SQL migrations in `supabase/migrations/` in your Supabase SQL Editor, in order:

1. `20261027132537_create_expense_tracker_schema.sql` — Creates `categories`, `transactions`, and `budgets` tables with RLS policies
2. `20261027132918_add_savings_goals.sql` — Creates `savings_goals` table with RLS policies

### Run

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Database Schema

### categories
| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| user_id | uuid | Owner (FK → auth.users) |
| name | text | Category name |
| type | text | 'income' or 'expense' |
| color | text | Hex color for UI |
| icon | text | Lucide icon name |
| created_at | timestamptz | Creation timestamp |

### transactions
| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| user_id | uuid | Owner (FK → auth.users) |
| amount | numeric(12,2) | Transaction amount (> 0) |
| type | text | 'income' or 'expense' |
| category_id | uuid | FK → categories (nullable) |
| description | text | Optional description |
| date | date | Transaction date |
| created_at | timestamptz | Creation timestamp |

### budgets
| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| user_id | uuid | Owner (FK → auth.users) |
| category_id | uuid | FK → categories |
| amount | numeric(12,2) | Monthly limit |
| month | date | First of month |

### savings_goals
| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| user_id | uuid | Owner (FK → auth.users) |
| name | text | Goal name |
| target_amount | numeric(12,2) | Target amount |
| current_amount | numeric(12,2) | Amount saved so far |
| target_date | date | Optional deadline |
| color | text | Hex color |
| completed | boolean | Auto-set when target reached |

import { useState } from 'react';
import { AuthProvider, useAuth } from '@/context/AuthContext';
import { ThemeProvider } from '@/context/ThemeContext';
import { Layout, type PageId } from '@/components/Layout';
import { AuthScreen } from '@/screens/AuthScreen';
import { LandingPage } from '@/screens/LandingPage';
import { Dashboard } from '@/screens/Dashboard';
import { Transactions } from '@/screens/Transactions';
import { Categories } from '@/screens/Categories';
import { Budgets } from '@/screens/Budgets';
import { SavingsGoals } from '@/screens/SavingsGoals';
import { Analytics } from '@/screens/Analytics';
import { useData } from '@/hooks/useData';

type AuthView = 'landing' | 'auth';

function AppContent() {
  const { user, loading } = useAuth();
  const [page, setPage] = useState<PageId>('dashboard');
  const [authView, setAuthView] = useState<AuthView>('landing');

  const data = useData(user?.id);

  if (loading) {
    return (
      <div className="min-h-screen flex items-center justify-center bg-slate-50 dark:bg-slate-950">
        <div className="w-10 h-10 border-4 border-emerald-200 border-t-emerald-600 rounded-full animate-spin" />
      </div>
    );
  }

  if (!user) {
    if (authView === 'landing') {
      return <LandingPage onGetStarted={() => setAuthView('auth')} />;
    }
    return <AuthScreen />;
  }

  return (
    <Layout current={page} onNavigate={setPage}>
      {page === 'dashboard' && (
        <Dashboard
          categories={data.categories}
          transactions={data.transactions}
          loading={data.loading}
        />
      )}
      {page === 'transactions' && (
        <Transactions
          categories={data.categories}
          transactions={data.transactions}
          loading={data.loading}
          onReload={data.reload}
        />
      )}
      {page === 'analytics' && (
        <Analytics
          categories={data.categories}
          transactions={data.transactions}
          loading={data.loading}
        />
      )}
      {page === 'budgets' && (
        <Budgets
          categories={data.categories}
          transactions={data.transactions}
          budgets={data.budgets}
          loading={data.loading}
          onReload={data.reload}
        />
      )}
      {page === 'goals' && (
        <SavingsGoals
          goals={data.goals}
          loading={data.loading}
          onReload={data.reload}
        />
      )}
      {page === 'categories' && (
        <Categories
          categories={data.categories}
          loading={data.loading}
          onReload={data.reload}
        />
      )}
    </Layout>
  );
}

export default function App() {
  return (
    <ThemeProvider>
      <AuthProvider>
        <AppContent />
      </AuthProvider>
    </ThemeProvider>
  );
}

import { useState } from 'react';

interface DonutSlice {
  label: string;
  value: number;
  color: string;
}

interface DonutChartProps {
  data: DonutSlice[];
  size?: number;
  thickness?: number;
  centerLabel?: string;
  centerValue?: string;
  centerSubValue?: string;
}

export function DonutChart({
  data,
  size = 200,
  thickness = 30,
  centerLabel,
  centerValue,
  centerSubValue,
}: DonutChartProps) {
  const [hovered, setHovered] = useState<number | null>(null);
  const total = data.reduce((sum, d) => sum + d.value, 0);
  const radius = (size - thickness) / 2;
  const circumference = 2 * Math.PI * radius;
  const cx = size / 2;
  const cy = size / 2;

  let offset = 0;
  const slices = total > 0
    ? data.filter((d) => d.value > 0).map((d) => {
        const fraction = d.value / total;
        const dash = fraction * circumference;
        const slice = {
          ...d,
          dashLength: dash,
          dashGap: circumference - dash,
          dashOffset: -offset,
          pct: fraction * 100,
        };
        offset += dash;
        return slice;
      })
    : [];

  const activeSlice = hovered !== null ? slices[hovered] : null;

  return (
    <div className="relative inline-flex items-center justify-center">
      <svg width={size} height={size} className="-rotate-90">
        <circle
          cx={cx}
          cy={cy}
          r={radius}
          fill="none"
          stroke="currentColor"
          strokeWidth={thickness}
          className="text-slate-100 dark:text-slate-800"
        />
        {slices.map((slice, i) => (
          <circle
            key={i}
            cx={cx}
            cy={cy}
            r={radius}
            fill="none"
            stroke={slice.color}
            strokeWidth={hovered === i ? thickness + 6 : thickness}
            strokeDasharray={`${slice.dashLength} ${slice.dashGap}`}
            strokeDashoffset={slice.dashOffset}
            strokeLinecap="butt"
            className="transition-all duration-300 cursor-pointer"
            style={{ opacity: hovered === null || hovered === i ? 1 : 0.4 }}
            onMouseEnter={() => setHovered(i)}
            onMouseLeave={() => setHovered(null)}
          />
        ))}
      </svg>
      {(centerLabel || centerValue) && (
        <div className="absolute inset-0 flex flex-col items-center justify-center pointer-events-none">
          {activeSlice ? (
            <>
              <span className="text-xs font-medium text-slate-400 uppercase tracking-wide mb-0.5">
                {activeSlice.label}
              </span>
              <span className="text-lg font-bold text-slate-900 dark:text-white">
                {new Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR', maximumFractionDigits: 0 }).format(activeSlice.value)}
              </span>
              <span className="text-xs text-slate-500 mt-0.5">{activeSlice.pct.toFixed(1)}%</span>
            </>
          ) : (
            <>
              {centerLabel && (
                <span className="text-xs font-medium text-slate-400 uppercase tracking-wide">
                  {centerLabel}
                </span>
              )}
              {centerValue && (
                <span className="text-xl font-bold text-slate-900 dark:text-white">{centerValue}</span>
              )}
              {centerSubValue && (
                <span className="text-xs text-slate-500 mt-0.5">{centerSubValue}</span>
              )}
            </>
          )}
        </div>
      )}
    </div>
  );
}

interface LineChartProps {
  data: { label: string; income: number; expense: number }[];
  height?: number;
}

export function LineChart({ data, height = 220 }: LineChartProps) {
  const width = 600;
  const padding = { top: 20, right: 16, bottom: 28, left: 16 };
  const chartW = width - padding.left - padding.right;
  const chartH = height - padding.top - padding.bottom;
  const maxVal = Math.max(...data.map((d) => Math.max(d.income, d.expense)), 100);

  const xStep = chartW / Math.max(data.length - 1, 1);

  function pointsFor(key: 'income' | 'expense') {
    return data.map((d, i) => {
      const x = padding.left + i * xStep;
      const y = padding.top + chartH - (d[key] / maxVal) * chartH;
      return { x, y };
    });
  }

  function smoothPath(pts: { x: number; y: number }[]) {
    if (pts.length < 2) return '';
    let path = `M ${pts[0].x},${pts[0].y}`;
    for (let i = 1; i < pts.length; i++) {
      const prev = pts[i - 1];
      const curr = pts[i];
      const cpx1 = prev.x + (curr.x - prev.x) / 2;
      const cpx2 = prev.x + (curr.x - prev.x) / 2;
      path += ` C ${cpx1},${prev.y} ${cpx2},${curr.y} ${curr.x},${curr.y}`;
    }
    return path;
  }

  function areaPath(pts: { x: number; y: number }[]) {
    const line = smoothPath(pts);
    if (!line) return '';
    const lastX = pts[pts.length - 1].x;
    const firstX = pts[0].x;
    const baseY = padding.top + chartH;
    return `${line} L ${lastX},${baseY} L ${firstX},${baseY} Z`;
  }

  const incomePts = pointsFor('income');
  const expensePts = pointsFor('expense');

  return (

interface SparklineProps {
  data: number[];
  color: string;
  width?: number;
  height?: number;
}

export function Sparkline({ data, color, width = 120, height = 36 }: SparklineProps) {
  if (data.length < 2) return null;
  const max = Math.max(...data, 1);
  const min = Math.min(...data, 0);
  const range = max - min || 1;
  const step = width / (data.length - 1);

  const pts = data.map((v, i) => ({
    x: i * step,
    y: height - ((v - min) / range) * (height - 4) - 2,
  }));

  let line = `M ${pts[0].x},${pts[0].y}`;
  for (let i = 1; i < pts.length; i++) {
    const prev = pts[i - 1];
    const curr = pts[i];
    const cpx = prev.x + (curr.x - prev.x) / 2;
    line += ` C ${cpx},${prev.y} ${cpx},${curr.y} ${curr.x},${curr.y}`;
  }

  const areaPath = `${line} L ${pts[pts.length - 1].x},${height} L ${pts[0].x},${height} Z`;
  const gradId = `spark-${color.replace('#', '')}`;

  return (
    <svg width={width} height={height} className="overflow-visible">
      <defs>
        <linearGradient id={gradId} x1="0" y1="0" x2="0" y2="1">
          <stop offset="0%" stopColor={color} stopOpacity="0.3" />
          <stop offset="100%" stopColor={color} stopOpacity="0" />
        </linearGradient>
      </defs>
      <path d={areaPath} fill={`url(#${gradId})`} />
      <path d={line} fill="none" stroke={color} strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" />
      <circle cx={pts[pts.length - 1].x} cy={pts[pts.length - 1].y} r="2.5" fill={color} />
    </svg>
  );
}

import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';
import type { Session, User } from '@supabase/supabase-js';
import { supabase } from '@/lib/supabase';

interface AuthContextValue {
  user: User | null;
  session: Session | null;
  loading: boolean;
  signUp: (email: string, password: string) => Promise<{ error: string | null }>;
  signIn: (email: string, password: string) => Promise<{ error: string | null }>;
  signOut: () => Promise<void>;
}

const AuthContext = createContext<AuthContextValue | undefined>(undefined);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<User | null>(null);
  const [session, setSession] = useState<Session | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    supabase.auth.getSession().then(({ data }) => {
      setSession(data.session);
      setUser(data.session?.user ?? null);
      setLoading(false);
    });

    const { data: sub } = supabase.auth.onAuthStateChange((_event, sess) => {
      setSession(sess);
      setUser(sess?.user ?? null);
      setLoading(false);
    });

    return () => sub.subscription.unsubscribe();
  }, []);

  async function signUp(email: string, password: string) {
    const { error } = await supabase.auth.signUp({ email, password });
    if (error) return { error: error.message };
    // Auto sign-in after sign-up since email confirmation is off
    const { error: signInError } = await supabase.auth.signInWithPassword({ email, password });
    if (signInError) return { error: signInError.message };
    return { error: null };
  }

  async function signIn(email: string, password: string) {
    const { error } = await supabase.auth.signInWithPassword({ email, password });
    if (error) return { error: error.message };
    return { error: null };
  }

  async function signOut() {
    await supabase.auth.signOut();
  }

  return (
    <AuthContext.Provider value={{ user, session, loading, signUp, signIn, signOut }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error('useAuth must be used within AuthProvider');
  return ctx;
}

import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';

type Theme = 'light' | 'dark';

interface ThemeContextValue {
  theme: Theme;
  toggle: () => void;
}

const ThemeContext = createContext<ThemeContextValue | undefined>(undefined);

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => {
    const saved = localStorage.getItem('finlytic-theme') as Theme | null;
    if (saved) return saved;
    return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
  });

  useEffect(() => {
    document.documentElement.classList.toggle('dark', theme === 'dark');
    localStorage.setItem('finlytic-theme', theme);
  }, [theme]);

  function toggle() {
    setTheme((prev) => (prev === 'dark' ? 'light' : 'dark'));
  }

  return (
    <ThemeContext.Provider value={{ theme, toggle }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider');
  return ctx;
}

import { useCallback, useEffect, useState } from 'react';
import { supabase } from '@/lib/supabase';
import type { Category, Transaction, Budget, SavingsGoal } from '@/lib/types';
import { seedDefaultCategories } from '@/lib/seed';

export interface MonthlyStats {
  income: number;
  expense: number;
  balance: number;
}

export function useData(userId: string | undefined) {
  const [categories, setCategories] = useState<Category[]>([]);
  const [transactions, setTransactions] = useState<Transaction[]>([]);
  const [budgets, setBudgets] = useState<Budget[]>([]);
  const [goals, setGoals] = useState<SavingsGoal[]>([]);
  const [loading, setLoading] = useState(true);

  const loadCategories = useCallback(async () => {
    if (!userId) return;
    const { data } = await supabase
      .from('categories')
      .select('*')
      .eq('user_id', userId)
      .order('name');
    if (data) setCategories(data);
  }, [userId]);

  const loadTransactions = useCallback(async () => {
    if (!userId) return;
    const { data } = await supabase
      .from('transactions')
      .select('*, category:categories(*)')
      .eq('user_id', userId)
      .order('date', { ascending: false })
      .order('created_at', { ascending: false });
    if (data) setTransactions(data as unknown as Transaction[]);
  }, [userId]);

  const loadBudgets = useCallback(async () => {
    if (!userId) return;
    const { data } = await supabase
      .from('budgets')
      .select('*, category:categories(*)')
      .eq('user_id', userId)
      .order('month', { ascending: false });
    if (data) setBudgets(data as unknown as Budget[]);
  }, [userId]);

  const loadGoals = useCallback(async () => {
    if (!userId) return;
    const { data } = await supabase
      .from('savings_goals')
      .select('*')
      .eq('user_id', userId)
      .order('created_at', { ascending: false });
    if (data) setGoals(data as SavingsGoal[]);
  }, [userId]);

  const reload = useCallback(async () => {
    await Promise.all([loadCategories(), loadTransactions(), loadBudgets(), loadGoals()]);
  }, [loadCategories, loadTransactions, loadBudgets, loadGoals]);

  useEffect(() => {
    if (!userId) return;
    (async () => {
      setLoading(true);
      await seedDefaultCategories(userId);
      await reload();
      setLoading(false);
    })();
  }, [userId, reload]);

  return {
    categories,
    transactions,
    budgets,
    goals,
    loading,
    reload,
    loadTransactions,
    loadBudgets,
    loadGoals,
    setTransactions,
  };
}

export function computeMonthlyStats(
  transactions: Transaction[],
  year: number,
  month: number
): MonthlyStats {
  let income = 0;
  let expense = 0;
  for (const t of transactions) {
    const d = new Date(t.date + 'T00:00:00');
    if (d.getFullYear() === year && d.getMonth() === month) {
      if (t.type === 'income') income += Number(t.amount);
      else expense += Number(t.amount);
    }
  }
  return { income, expense, balance: income - expense };
}

export function exportTransactionsCSV(transactions: Transaction[]): void {
  const headers = ['Date', 'Type', 'Category', 'Description', 'Amount'];
  const rows = transactions.map((t) => [
    t.date,
    t.type,
    t.category?.name ?? 'Uncategorized',
    t.description ?? '',
    String(t.amount),
  ]);

  const csv = [headers, ...rows]
    .map((row) => row.map((field) => `"${field.replace(/"/g, '""')}"`).join(','))
    .join('\n');

  const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = `transactions-${new Date().toISOString().slice(0, 10)}.csv`;
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
  URL.revokeObjectURL(url);
}

      expense += m.expense;
    }
    return { income, expense, balance: income - expense, savingsRate: income > 0 ? ((income - expense) / income) * 100 : 0 };
  }, [monthlyData]);

  // Top expense categories (year)
  const topCategories = useMemo(() => {
    const map = new Map<string, number>();
    for (const t of transactions) {
      if (t.type !== 'expense') continue;
      const d = new Date(t.date + 'T00:00:00');
      if (d.getFullYear() !== year) continue;
      const cat = t.category ?? categories.find((c) => c.id === t.category_id);
      const key = cat?.id ?? 'uncat';
      map.set(key, (map.get(key) ?? 0) + Number(t.amount));
    }
    const total = Array.from(map.values()).reduce((s, v) => s + v, 0);
    return Array.from(map.entries())
      .map(([catId, value]) => {
        const cat = categories.find((c) => c.id === catId);
        return {
          label: cat?.name ?? 'Uncategorized',
          value,
          color: cat?.color ?? '#94a3b8',
          pct: total > 0 ? (value / total) * 100 : 0,
        };
      })
      .sort((a, b) => b.value - a.value);
  }, [transactions, categories, year]);

  // Month-over-month trend
  const monthTrend = useMemo(() => {
    const currentMonth = monthlyData[cursor.getMonth()];
    const prevIdx = cursor.getMonth() === 0 ? 11 : cursor.getMonth() - 1;
    const prevMonth = cursor.getMonth() === 0 ? monthlyData[11] : monthlyData[cursor.getMonth() - 1];
    const incomeChange = prevMonth.income > 0 ? ((currentMonth.income - prevMonth.income) / prevMonth.income) * 100 : 0;
    const expenseChange = prevMonth.expense > 0 ? ((currentMonth.expense - prevMonth.expense) / prevMonth.expense) * 100 : 0;
    return { currentMonth, prevMonth, incomeChange, expenseChange };
  }, [monthlyData, cursor]);

  // Average per transaction
  const avgTransaction = useMemo(() => {
    const yearTx = transactions.filter((t) => new Date(t.date + 'T00:00:00').getFullYear() === year);
    if (yearTx.length === 0) return 0;
    const total = yearTx.reduce((sum, t) => sum + Number(t.amount), 0);
    return total / yearTx.length;
  }, [transactions, year]);

  // Biggest transaction
  const biggestExpense = useMemo(() => {
    const yearExp = transactions.filter((t) => {
      if (t.type !== 'expense') return false;
      return new Date(t.date + 'T00:00:00').getFullYear() === year;
    });
    if (yearExp.length === 0) return null;
    return yearExp.reduce((max, t) => (Number(t.amount) > Number(max.amount) ? t : max));
  }, [transactions, year]);

  // Best saving month
  const bestMonth = useMemo(() => {
    let best = monthlyData[0];
    let bestIdx = 0;
    monthlyData.forEach((m, i) => {
      if (m.balance > best.balance) { best = m; bestIdx = i; }
    });
    return { ...best, idx: bestIdx };
  }, [monthlyData]);

  const prevYear = () => setCursor(new Date(year - 1, cursor.getMonth(), 1));
  const nextYear = () => setCursor(new Date(year + 1, cursor.getMonth(), 1));

  const donutData = topCategories.map((c) => ({ label: c.label, value: c.value, color: c.color }));

  return (
    <div className="space-y-6 animate-fade-in">
      {/* Header */}
      <div className="flex flex-col sm:flex-row sm:items-center justify-between gap-4">
        <div>
          <h1 className="text-2xl font-bold text-slate-900">Analytics</h1>

            <ArrowDown size={16} className="rotate-[-90deg]" />
          </button>
        </div>
      </div>

      {loading ? (
        <div className="card p-12 text-center text-slate-400 text-sm">Loading…</div>

        <div className="card p-12 text-center">
          <p className="text-slate-400 text-sm">Add transactions to see analytics.</p>
        </div>

            <div className="card p-5 bg-emerald-50 border-0">
              <div className="flex items-center justify-between mb-3">
                <span className="text-sm font-medium text-slate-600">Year Income</span>

                  <TrendingUp size={18} className="text-emerald-600" />

import { useMemo, useState } from 'react';
import { supabase } from '@/lib/supabase';
import { useAuth } from '@/context/AuthContext';
import type { Budget, Category, Transaction } from '@/lib/types';
import { formatCurrency, formatMonth, monthKey } from '@/lib/format';
import { Modal } from '@/components/Modal';
import { Plus, Pencil, Trash2, Target, TrendingUp, AlertTriangle, CheckCircle2 } from 'lucide-react';

interface BudgetsProps {
  categories: Category[];
  transactions: Transaction[];
  budgets: Budget[];
  loading: boolean;
  onReload: () => Promise<void>;
}

interface FormState {
  category_id: string;
  amount: string;
  month: string;
}

export function Budgets({ categories, transactions, budgets, loading, onReload }: BudgetsProps) {
  const { user } = useAuth();
  const [modalOpen, setModalOpen] = useState(false);
  const [editing, setEditing] = useState<Budget | null>(null);
  const [form, setForm] = useState<FormState>({ category_id: '', amount: '', month: monthKey(new Date()) });
  const [saving, setSaving] = useState(false);
  const [confirmDelete, setConfirmDelete] = useState<Budget | null>(null);
  const [month, setMonth] = useState(() => new Date());

  const expenseCategories = useMemo(() => categories.filter((c) => c.type === 'expense'), [categories]);

  const monthBudgets = useMemo(() => {
    const key = monthKey(month);
    return budgets.filter((b) => b.month === key);
  }, [budgets, month]);

  const spendByCategory = useMemo(() => {
    const map = new Map<string, number>();
    for (const t of transactions) {
      if (t.type !== 'expense' || !t.category_id) continue;
      const d = new Date(t.date + 'T00:00:00');
      if (d.getFullYear() === month.getFullYear() && d.getMonth() === month.getMonth()) {
        map.set(t.category_id, (map.get(t.category_id) ?? 0) + Number(t.amount));
      }
    }
    return map;
  }, [transactions, month]);

  const totalBudget = monthBudgets.reduce((sum, b) => sum + Number(b.amount), 0);
  const totalSpent = monthBudgets.reduce((sum, b) => sum + (spendByCategory.get(b.category_id) ?? 0), 0);

  function openAdd() {
    setEditing(null);
    setForm({ category_id: '', amount: '', month: monthKey(month) });
    setModalOpen(true);
  }

  function openEdit(b: Budget) {
    setEditing(b);
    setForm({ category_id: b.category_id, amount: String(b.amount), month: b.month });
    setModalOpen(true);
  }

  async function handleSave() {
    if (!user || !form.category_id || !form.amount) return;
    setSaving(true);
    const payload = {
      user_id: user.id,
      category_id: form.category_id,
      amount: parseFloat(form.amount),
      month: form.month,
    };
    if (editing) {
      await supabase.from('budgets').update({ amount: parseFloat(form.amount) }).eq('id', editing.id);
    } else {
      await supabase.from('budgets').insert(payload);
    }
    setSaving(false);
    setModalOpen(false);
    await onReload();
  }

  async function handleDelete() {
    if (!confirmDelete) return;
    await supabase.from('budgets').delete().eq('id', confirmDelete.id);
    setConfirmDelete(null);
    await onReload();
  }

  const prevMonth = () => setMonth(new Date(month.getFullYear(), month.getMonth() - 1, 1));
  const nextMonth = () => setMonth(new Date(month.getFullYear(), month.getMonth() + 1, 1));

  const overallPct = totalBudget > 0 ? (totalSpent / totalBudget) * 100 : 0;
  const overallStatus =
    overallPct >= 100 ? 'over' : overallPct >= 80 ? 'warning' : 'ok';

  return (
    <div className="space-y-6 animate-fade-in">
      <div className="flex flex-col sm:flex-row sm:items-center justify-between gap-4">
        <div>
          <h1 className="text-2xl font-bold text-slate-900">Budgets</h1>
          <p className="text-slate-500 text-sm mt-1">Set monthly spending limits per category.</p>
        </div>
        <div className="flex items-center gap-2">
          <button onClick={prevMonth} className="btn-secondary !p-2.5">‹</button>
          <span className="px-4 py-2.5 text-sm font-semibold text-slate-700 min-w-[10rem] text-center">
            {formatMonth(monthKey(month))}
          </span>
          <button onClick={nextMonth} className="btn-secondary !p-2.5">›</button>
          <button onClick={openAdd} className="btn-primary ml-2">
            <Plus size={18} /> Add Budget
          </button>
        </div>
      </div>

      {/* Overall progress */}

        <div className="card p-6">
          <div className="flex items-center justify-between mb-3">
            <div className="flex items-center gap-3">
              <div className={`w-10 h-10 rounded-xl flex items-center justify-center ${
                overallStatus === 'over' ? 'bg-red-100 text-red-600'
                  : overallStatus === 'warning' ? 'bg-amber-100 text-amber-600'
                  : 'bg-emerald-100 text-emerald-600'
              }`}>
                {overallStatus === 'over' ? <AlertTriangle size={20} /> : <Target size={20} />}
              </div>
              <div>
                <p className="text-sm font-semibold text-slate-900">Total Budget</p>
                <p className="text-xs text-slate-500">{formatCurrency(totalSpent)} of {formatCurrency(totalBudget)} spent</p>
              </div>
            </div>
            <span className={`text-2xl font-bold ${
              overallStatus === 'over' ? 'text-red-600'
                : overallStatus === 'warning' ? 'text-amber-600'
                : 'text-emerald-600'
            }`}>
              {overallPct.toFixed(0)}%
            </span>
          </div>
          <div className="h-3 rounded-full bg-slate-100 overflow-hidden">
            <div
              className={`h-full rounded-full transition-all duration-500 ${
                overallStatus === 'over' ? 'bg-red-500'
                  : overallStatus === 'warning' ? 'bg-amber-500'
                  : 'bg-emerald-500'
              }`}
              style={{ width: `${Math.min(overallPct, 100)}%` }}
            />

      await supabase.from('categories').insert(payload);

    setSaving(false);
    setModalOpen(false);
    await onReload();

interface DashboardProps {
  categories: Category[];
  transactions: Transaction[];
  loading: boolean;
}

export function Dashboard({ categories, transactions, loading }: DashboardProps) {
  const [cursor, setCursor] = useState(() => {
    const d = new Date();
    return new Date(d.getFullYear(), d.getMonth(), 1);
  });

  const stats = useMemo(
    () => computeMonthlyStats(transactions, cursor.getFullYear(), cursor.getMonth()),
    [transactions, cursor]
  );

  const prevStats = useMemo(
    () => computeMonthlyStats(transactions, cursor.getFullYear(), cursor.getMonth() - 1),
    [transactions, cursor]
  );

  const expenseByCategory = useMemo(() => {
    const map = new Map<string, number>();
    for (const t of transactions) {
      if (t.type !== 'expense') continue;
      const d = new Date(t.date + 'T00:00:00');
      if (d.getFullYear() === cursor.getFullYear() && d.getMonth() === cursor.getMonth()) {
        const cat = t.category ?? categories.find((c) => c.id === t.category_id);
        const key = cat?.id ?? 'uncat';
        map.set(key, (map.get(key) ?? 0) + Number(t.amount));
      }
    }
    return Array.from(map.entries())
      .map(([catId, value]) => {
        const cat = categories.find((c) => c.id === catId);
        return { label: cat?.name ?? 'Uncategorized', value, color: cat?.color ?? '#94a3b8' };
      })
      .sort((a, b) => b.value - a.value);
  }, [transactions, categories, cursor]);

  const lastSixMonths = useMemo(() => {
    const months: { label: string; income: number; expense: number }[] = [];
    for (let i = 5; i >= 0; i--) {
      const d = new Date(cursor.getFullYear(), cursor.getMonth() - i, 1);
      const s = computeMonthlyStats(transactions, d.getFullYear(), d.getMonth());
      months.push({
        label: d.toLocaleDateString('en-IN', { month: 'short' }),
        income: s.income,
        expense: s.expense,
      });
    }
    return months;
  }, [transactions, cursor]);

  // 6-month sparklines for stat cards

  const expenseSpark = useMemo(() => lastSixMonths.map((m) => m.expense), [lastSixMonths]);
  const balanceSpark = useMemo(() => lastSixMonths.map((m) => m.income - m.expense), [lastSixMonths]);

  // Daily spending for current month
  const dailySpending = useMemo(() => {

    const today = new Date();

    const cutoff = isCurrentMonth ? today.getDate() : daysInMonth;

      const d = new Date(t.date + 'T00:00:00');
      if (d.getFullYear() === cursor.getFullYear() && d.getMonth() === cursor.getMonth()) {
        buckets[d.getDate() - 1] += Number(t.amount);
      }
    }
    return { buckets: buckets.slice(0, cutoff), daysInMonth, cutoff };
  }, [transactions, cursor]);

  const recent = useMemo(() => transactions.slice(0, 7), [transactions]);

  // Insights
  const topCategory = expenseByCategory[0] ?? null;
  const savingsRate = stats.income > 0 ? (stats.balance / stats.income) * 100 : 0;
  const monthTxCount = transactions.filter((t) => {
    const d = new Date(t.date + 'T00:00:00');
    return d.getFullYear() === cursor.getFullYear() && d.getMonth() === cursor.getMonth();
  }).length;
  const avgDailySpending = dailySpending.cutoff > 0 ? stats.expense / dailySpending.cutoff : 0;

// --- Stat card with sparkline + trend ---
interface StatCardProps {
  label: string;
  value: string;
  icon: typeof Wallet;
  iconBg: string;
  iconColor: string;
  cardBg: string;
  sparkData: number[];
  sparkColor: string;
  trend: number | null;
  trendGood: (v: number) => boolean;
}

function StatCard({ label, value, icon: Icon, iconBg, iconColor, cardBg, sparkData, sparkColor, trend, trendGood }: StatCardProps) {
  return (
    <div className={`card p-5 ${cardBg} border-slate-200/80 dark:border-slate-700/50 flex flex-col justify-between`}>
      <div className="flex items-center justify-between mb-3">
        <span className="text-sm font-medium text-slate-600 dark:text-slate-300">{label}</span>
        <div className={`w-9 h-9 rounded-xl ${iconBg} flex items-center justify-center`}>
          <Icon size={18} className={iconColor} />
        </div>
      </div>
      <div className="flex items-end justify-between">
        <div>
          <p className="text-2xl font-bold text-slate-900 dark:text-white">{value}</p>
          {trend !== null && (
            <span className={`text-xs font-semibold mt-1 flex items-center gap-0.5 ${
              trendGood(trend) ? 'text-emerald-600 dark:text-emerald-400' : 'text-rose-600 dark:text-rose-400'
            }`}>
              {trend >= 0 ? <ArrowUp size={11} /> : <ArrowDown size={11} />}
              {Math.abs(trend).toFixed(1)}% vs last month
            </span>
          )}
        </div>
        <Sparkline data={sparkData} color={sparkColor} width={90} height={36} />
      </div>
    </div>
  );
}

// --- Mini stat ---
interface MiniStatProps {
  label: string;
  value: string;
  subValue?: string;
  icon: typeof Wallet;
  iconBg: string;
  iconColor: string;
}

function MiniStat({ label, value, subValue, icon: Icon, iconBg, iconColor }: MiniStatProps) {
  return (
    <div className="card p-4">
      <div className="flex items-center gap-2.5 mb-2">
        <div className={`w-8 h-8 rounded-lg ${iconBg} flex items-center justify-center shrink-0`}>
          <Icon size={16} className={iconColor} />
        </div>
        <span className="text-xs font-medium text-slate-500 dark:text-slate-400 truncate">{label}</span>
      </div>
      <p className="text-lg font-bold text-slate-900 dark:text-white truncate">{value}</p>
      {subValue && <p className="text-xs text-slate-400 dark:text-slate-500 mt-0.5">{subValue}</p>}
    </div>
  );
}

        (t.category?.name ?? '').toLowerCase().includes(q)
      );
    }
    if (filterType !== 'all') result = result.filter((t) => t.type === filterType);
    if (filterCat !== 'all') result = result.filter((t) => t.category_id === filterCat);

    result.sort((a, b) => {
      switch (sortBy) {
        case 'date-asc': return a.date.localeCompare(b.date);
        case 'amount-desc': return Number(b.amount) - Number(a.amount);
        case 'amount-asc': return Number(a.amount) - Number(b.amount);
        default: return b.date.localeCompare(a.date);
      }
    });
    return result;

                      className="p-2 rounded-lg text-slate-400 hover:text-slate-700 hover:bg-slate-100 transition-colors opacity-0 group-hover:opacity-100"
                    >
                      <Pencil size={16} />
                    </button>
                    <button
                      onClick={() => handleDelete(t.id)}
                      className="p-2 rounded-lg text-slate-400 hover:text-red-600 hover:bg-red-50 transition-colors opacity-0 group-hover:opacity-100"
                    >
                      <Trash2 size={16} />
                    </button>
                  </div>
                </div>
              );
            })}
          </div>
        )}
      </div>

      {/* Modal */}
      <Modal
        open={modalOpen}
        onClose={() => setModalOpen(false)}
        title={editing ? 'Edit Transaction' : 'Add Transaction'}
      >
        <div className="space-y-4">
          {/* Type toggle */}
          <div className="grid grid-cols-2 gap-2 p-1 bg-slate-100 rounded-xl">
            <button
              onClick={() => { setForm({ ...form, type: 'expense', category_id: '' }); }}
              className={`py-2.5 rounded-lg text-sm font-semibold transition-all ${
                form.type === 'expense' ? 'bg-white text-rose-600 shadow-sm' : 'text-slate-500'
              }`}
            >
              Expense
            </button>
            <button
              onClick={() => { setForm({ ...form, type: 'income', category_id: '' }); }}
              className={`py-2.5 rounded-lg text-sm font-semibold transition-all ${
                form.type === 'income' ? 'bg-white text-emerald-600 shadow-sm' : 'text-slate-500'
              }`}
            >
              Income
            </button>
          </div>

          <div>
            <label className="label">Amount</label>
            <div className="relative">
              <span className="absolute left-4 top-1/2 -translate-y-1/2 text-slate-400 font-medium">₹</span>
              <input
                type="number"
                step="0.01"
                min="0"
                required
                value={form.amount}
                onChange={(e) => setForm({ ...form, amount: e.target.value })}
                placeholder="0.00"
                className="input pl-8"
              />
            </div>
          </div>

          <div>
            <label className="label">Category</label>
            <select
              value={form.category_id}
              onChange={(e) => setForm({ ...form, category_id: e.target.value })}
              className="input cursor-pointer"
            >
              <option value="">Uncategorized</option>
              {availableCategories.map((c) => (
                <option key={c.id} value={c.id}>{c.name}</option>
              ))}
            </select>
          </div>

          <div>
            <label className="label">Description (optional)</label>
            <input
              type="text"
              value={form.description}
              onChange={(e) => setForm({ ...form, description: e.target.value })}
              placeholder="e.g. Coffee at Starbucks"
              className="input"
            />
          </div>

          <div>
            <label className="label">Date</label>
            <input
              type="date"
              required
              value={form.date}
              onChange={(e) => setForm({ ...form, date: e.target.value })}
              className="input cursor-pointer"
            />
          </div>

          <button onClick={handleSave} disabled={saving} className="btn-primary w-full">
            {saving ? 'Saving…' : editing ? 'Save changes' : 'Add transaction'}
          </button>
        </div>
      </Modal>
    </div>
  );
}

1. Overview
Creates the core tables for a multi-user expense tracker app:
- categories: user-defined income/expense categories (e.g. "Salary", "Food")
- transactions: individual income/expense entries
- budgets: monthly spending limits per expense category

2. New Tables
- categories

  - amount (numeric, not null, > 0)
  - type (text, 'income' | 'expense')
  - category_id (uuid FK -> categories, nullable, ON DELETE SET NULL)
  - description (text, nullable)
  - date (date, not null)
  - created_at (timestamptz)
- budgets
  - id (uuid PK)
  - user_id (uuid, owner, defaults to auth.uid())
  - category_id (uuid FK -> categories, ON DELETE CASCADE)
  - amount (numeric, not null, > 0)
  - month (date, first of month, not null)
  - created_at (timestamptz)

3. Security
- RLS enabled on all three tables.
- All policies scoped TO authenticated with auth.uid() = user_id ownership checks.
- Grants limited to authenticated role for the verbs the app uses.
- Unique constraint prevents duplicate (user, category, month) budgets.

4. Indexes
- transactions(user_id, date desc) for dashboard queries
- transactions(user_id, category_id) for category reports
- categories(user_id) for listing
- budgets(user_id, month) for budget lookups
*/

  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL DEFAULT auth.uid() REFERENCES auth.users(id) ON DELETE CASCADE,
  name text NOT NULL,
  type text NOT NULL CHECK (type IN ('income', 'expense')),
  color text NOT NULL DEFAULT '#10b981',
  icon text NOT NULL DEFAULT 'Wallet',
  created_at timestamptz NOT NULL DEFAULT now()
);
